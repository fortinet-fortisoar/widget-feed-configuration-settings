# Feed Configuration Settings

The feed configuration settings widget is applicable to the **Feed Configurations** tab of the `Threat Intel Management` page for configuring feeds to be consumed by the *Threat Intel Feed* module.

**Feed Configuration Settings - Threat Intel Management page**:

Once you add the Feed Configuration Settings widget, you will see the following when you navigate to **Threat Intel Management** > **Feed Configurations** > **Threat Feed Rules**:
